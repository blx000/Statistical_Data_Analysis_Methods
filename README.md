# Методы статистического анализа данных

**Python · Jupyter Notebook · Математическая статистика**

Учебный репозиторий с лабораторными работами по дисциплине «Методы статистического анализа данных». Здесь собраны практические задания по описательной статистике, исследованию распределений, выборочному наблюдению, статистическому оцениванию и проверке гипотез.

Работы выполняются в рамках университетского курса. **Репозиторий пополняется по мере прохождения новых тем.**

## О проекте

Цель работ — научиться исследовать данные с помощью статистических методов: переходить от выборки к её числовым характеристикам, анализировать распределения, оценивать параметры и проверять статистические предположения.

Основные направления:

- **Описательная статистика:** представление выборочных данных и исследование их характеристик.
- **Распределения:** изучение свойств нормального распределения.
- **Выборочный анализ:** работа с выборкой и статистическими оценками.
- **Проверка гипотез:** формулирование статистических предположений и интерпретация результатов проверки.

### Модуль 1. Описательная статистика и распределения

**ЛР 1.1 — Статистические ряды**

Знакомство с представлением эмпирических данных и описанием выборки. Тема формирует основу для дальнейшего статистического анализа.

**ЛР 1.2 — Нормальное распределение**

Изучение нормальной модели распределения и её применения при анализе случайных величин.

### Модуль 2. Выборки и оценивание

**ЛР 2.1 — Выборочное наблюдение**

Исследование данных на основе выборки и переход от отдельных наблюдений к статистическим характеристикам.

**ЛР 2.2 — Статистические оценки**

Знакомство с оцениванием параметров генеральной совокупности по выборочным данным и смыслом полученных оценок.

### Модуль 3. Проверка статистических гипотез

**ЛР 3.1 — Гипотеза о нормальном распределении**

Исследование предположения о соответствии распределения нормальной модели.

**ЛР 3.2 — Гипотеза о равенстве дисперсий**

Исследование предположения об одинаковой изменчивости в двух совокупностях.

Работы этого модуля развивают навыки постановки статистических гипотез и интерпретации решений, которые полезны при дальнейшем изучении экспериментального анализа и A/B-тестирования.

## Как открыть и запустить

**Вариант 1 — через GitHub**

Откройте нужную лабораторную по ссылке в таблице выше. GitHub позволяет просматривать `.ipynb` непосредственно в репозитории.

**Вариант 2 — локально в Jupyter Notebook**

Клонируйте репозиторий:

```bash
git clone https://github.com/blx000/Statistical_Data_Analysis_Methods.git
cd Statistical_Data_Analysis_Methods
```

Запустите Jupyter Notebook:

```bash
jupyter notebook
```

Откройте нужную лабораторную работу и последовательно выполните ячейки.

Для запуска потребуются Python, Jupyter Notebook и библиотеки, используемые в соответствующей работе. Если ноутбук читает файлы, необходимо проверить пути к данным.
